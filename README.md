# Fruit Blends: Zero-Gravity Showcase

An immersive, high-end creative tech portfolio web application built with React, Vite, Matter.js 2D physics engine, Framer Motion, and Tailwind CSS. This project combines hyper-realistic 2D physics alchemy, dynamic macro telemetry, and futuristic glassmorphism UI design.

## ✨ Key Features & Architecture

### 1. Aesthetic Foundation & Design System
* **Deep Void Canvas:** Styled with a dark theme (`#08080C`) featuring an SVG noise filter overlay and grid accents.
* **Glassmorphism UI:** Frosted glass panels (`rgba(255, 255, 255, 0.03)`) with `backdrop-filter: blur(24px)` and subtle borders.
* **Dynamic Accent Themes:** Auto-switching background radial mesh gradients per flavor (e.g., Dragonfruit Blast, Citrus Burst, Matcha Mint, and Berry Galaxy).
* **Typography:** Clean layout utilizing Clash Display for titles and Plus Jakarta Sans for body copy.

### 2. Physics Engine & Interactivity
* **Matter.js 2D Physics Engine:** Powers a zero-gravity anti-gravity field (`gravity.y = -0.02` / buoyancy mode) with high-DPI vector canvas rendering.
* **Interactive Elements:** Features sliced fruits (pitaya, orange, kiwi, blueberry), zero-gravity crystal ice cubes, and micro-droplets with radial glow.
* **Kinetic Cursor Force Field:** Cursor speed creates repulsive shockwaves that interact dynamically with floating physics bodies.

### 3. Interactive Alchemy Station ("Mix & Blend Lab")
* **Custom Elixir Creation:** Users can drag or tap raw botanicals and ingredients to craft custom anti-gravity elixirs.
* **Real-Time Wave Physics:** Liquid levels inside the vessel rise dynamically with live wave simulations.

### 4. Live Bio-Telemetry & Macro Analysis
* Real-time metrics tracking for **Antioxidant Density**, **Natural Sugars**, **Hydration Index**, and **Vitamin C Coverage**.
* **Gyroscopic 3D Parallax Gallery:** Signature blend cards with 3D tilt dynamics on hover.

## 🛠️ Built With

* **React 18** — Frontend UI library
* **Vite** — Lightning-fast build tool and dev server
* **Matter.js** — 2D rigid body physics engine
* **Framer Motion** — Production-ready motion and layout animations
* **Tailwind CSS** — Utility-first CSS framework
* **Web Audio API** — Interactive soundscape integration
